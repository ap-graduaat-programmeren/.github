# Welkom bij AP Graduaat Programmeren

Deze GitHub-organisatie is de gezamenlijke werkruimte voor het graduaat Programmeren aan AP. Je vindt hier repositories met lesmateriaal, oefeningen en projecten. Fijn dat je er bent!

## Aan de slag

1. **Zoek de juiste repository.** Bekijk de repositories van deze organisatie en kies de repository die bij je vak, opdracht of project hoort. De README van die repository vertelt wat erin staat en hoe je ermee aan de slag gaat.
2. **Lees de lokale afspraken.** Controleer vóór je begint de README en eventuele bestanden zoals `CONTRIBUTING.md`. Opdrachten kunnen eigen instructies, deadlines en afspraken hebben; die gaan voor op deze algemene handleiding.
3. **Werk vanuit je eigen kopie of branch.** Maak een fork of een nieuwe branch, afhankelijk van de instructies van de repository. Pas bestanden daar aan en commit je wijzigingen met een duidelijke beschrijving.
4. **Deel je bijdrage.** Open een pull request als je wijzigingen wilt laten nakijken of samenvoegen. Beschrijf wat je hebt aangepast en verwijs zo nodig naar de bijbehorende opdracht of issue.

## Problemen of vragen?

- Kijk eerst of de README, opdrachtinstructies of bestaande issues je vraag beantwoorden.
- Gebruik Issues voor een concrete foutmelding, verbetering of vraag over een repository. Vermeld welke repository het betreft en hoe iemand het probleem kan reproduceren. Deel geen wachtwoorden, tokens of andere geheime gegevens.
- Weet je niet waar je vraag thuishoort of heb je toegang nodig? Neem contact op met je docent of de beheerder van de betreffende repository.

## Goed om te weten

- Volg altijd de instructies in de repository waaraan je werkt; deze kunnen per vak of project verschillen.
- Bewaar persoonlijke gegevens, wachtwoorden, API-sleutels en andere vertrouwelijke informatie niet in code, issues of pull requests.
- Controleer vóór je een wijziging deelt dat je de juiste bestanden hebt aangepast en dat je opdracht of project nog werkt.
